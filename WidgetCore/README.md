# WidgetCore

Общая библиотека редактора (`MyWidgetEditor`) и рантайма (`Drawer`). Здесь живут все виджеты,
конфиг, связи и шина событий. Код виджета пишется один раз и работает в обоих приложениях.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `core/Widget.h` | Базовый класс виджета: позиция, размер, порты, `Emit`, (де)сериализация |
| `core/WidgetContext.h` | Где сейчас работает виджет: редактор или Drawer, превью или живые данные |
| `core/EventBus.h` | Шина событий: доставка данных между виджетами |
| `core/Ports.h` | Порты и связи (`PortDesc`, `Connection`) |
| `core/Config.h` | Загрузка и сохранение конфига `.json` |
| `core/WindowProperties.h` | Свойства окна Drawer: фон, шейдер, режим обоев и т.д. |
| `core/WidgetFactory.h` | Создание виджета по имени класса |
| `widgets/*` | Сами виджеты |
| `widgets/RegisterAllWidgets.cpp` | Список всех виджетов для фабрики |

Перетаскивание, ресайз и выделение — не здесь, а в редакторе (`MyWidgetEditor/src/managers/WidgetManager`).

## Как добавить виджет

1. Создать `widgets/MyWidget.h/.cpp`, класс `core::MyWidget : public core::Widget`.
   В конструкторе передать тип и размер по умолчанию: `Widget(WidgetType::CUSTOM, ImVec2(200, 100))`.
2. Переопределить нужное (всё необязательно):
   - `Update()` — логика кадра (таймеры, приём результатов фоновой загрузки);
   - `Render(draw_list, min, max)` — рисование через `ImDrawList`;
   - `RenderContent(min, max)` — обычные ImGui-элементы (таблицы, графики, поля);
   - `RenderProperties()` — панель свойств в редакторе;
   - `ToJson()` / `FromJson()` — сохранение настроек (сначала вызвать версию `Widget::`);
   - `GetInputPorts()` / `GetOutputPorts()` / `OnInput()` — порты.
3. Добавить строку в `RegisterAllWidgets.cpp`:
   `WidgetFactory::Register<MyWidget>("MyWidget");`

Всё. Виджет появится в списке шаблонов редактора и будет работать в Drawer. CMake подхватит новые файлы сам.

## Как ходят данные

```
Table.Emit("data", rows) ──► EventBus (очередь) ──► раз за кадр Dispatch() ──► Plot.OnInput("data", ...)
```

- Связи рисуются в редакторе мышью и хранятся в конфиге: `from_widget/from_port → to_widget/to_port`.
- `Emit()` только кладёт сообщение в очередь, поэтому его можно вызывать из любого потока.
- `OnInput()` всегда вызывается на главном потоке, после `Update()` всех виджетов.
- Если виджет отправит данные внутри `OnInput()`, они дойдут в следующем кадре (зацикливания не будет).
- `OnPortsConnected()` вызывается, когда связи поменялись: так новый подписчик может сразу
  получить последние данные (см. `TableWidget`).

## Превью и живые данные

В редакторе есть галка **Live data**. Виджет узнаёт режим через `ShowsPreview()`:

- `true` — редактор с выключенной галкой: показывать тестовые данные, никуда не ходить по сети;
- `false` — Drawer или редактор с включённой галкой: работать по-настоящему.

При переключении вызывается `OnContextChanged()`.

## Фоновые потоки

OpenGL и ImGui — только на главном потоке. Пример безопасной загрузки — `TableWidget`:
поток грузит данные и кладёт их в поле под мьютексом, а `Update()` на главном потоке забирает их
и вызывает `Emit()`. Поток (`std::jthread`) объявлен последним полем класса — тогда при удалении
виджета он завершается раньше, чем исчезнут данные, которые он использует.
